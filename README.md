# 🧮 Calculator App

A simple and interactive calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations and includes a calculation history feature.

## ✨ Features

- Addition, subtraction, multiplication, and division
- Clear and delete functions
- Decimal number support
- Calculation history
- Simple and user-friendly interface
- Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
